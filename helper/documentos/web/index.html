Tipo de extracción
Una URL por línea, solo del portal principal UNAMBA. Antes de extraer se verifica que sea accesible desde sus enlaces visibles; una URL escrita manualmente no autoriza rutas ocultas. Hasta 200 URLs.
Solo www.unamba.edu.pe y unamba.edu.pe. Recorre enlaces visibles y menús desplegables; excluye otros dominios, subdominios y enlaces técnicos.
La extracción usa Firecrawl y consume créditos de tu cuenta. Los PDFs, imágenes enlazadas, subdominios y páginas externas no se extraen.

CAMBIOS RECUPERABLES

Respaldos del documento

Al restaurar una versión se respalda primero el documento actual.

Un flujo simple, de principio a fin

  1. Añade fuentes. Extrae URLs con Firecrawl, importa archivos .md o .txt, o crea un documento.
  2. Revisa el contenido. Edita los textos, conserva los encabezados y verifica la URL de origen. Cada guardado crea un respaldo.
  3. Actualiza el conocimiento. Con Ollama abierto y el modelo de embeddings disponible, pulsa «Actualizar índice».
  4. Recarga el chatbot. Usa /recargar o reinícialo para consultar el índice actualizado.
La papelera y los respaldos se guardan fuera de data/raw y nunca se indexan. Mientras hay un proceso activo, se bloquean los cambios desde este panel.
